Pocket Vision Lab

Three Google MediaPipe vision models running on your phone’s camera. Frames never leave the device — the model weights and the WebAssembly runtime are served with this page and execute in the browser.

Heads up Camera access is blocked inside an embedded preview. Open this page in its own tab to use the camera.

Start the camera to see live model output. Hands mode reports handedness, the recognized gesture, and its confidence for each hand in frame.

PrivacyNothing is uploaded. getUserMedia frames go straight into the WebAssembly graph and are discarded. There is no network call after the model loads.
iOSSafari 16.4 or newer. Camera capture needs HTTPS, a real tap to start, and a top-level page — iOS blocks capture in cross-origin embeds.
BackendGPU first, CPU fallback. The graph is built against the WebGL delegate and rebuilt on CPU if that fails. The Delegate readout shows which one was requested — MediaPipe may still route individual ops to CPU.
ModelsGesture Recognizer, Face Landmarker, Pose Landmarker (lite). Each is fetched once on first use, then cached by the browser.
